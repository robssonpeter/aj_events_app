# Release notes — v1.2.4+13

## Google Play — "What's new" (release notes field)

New: Contribution rounds (mchango) — track pledges, record payments, and
send contributor cards straight from your phone.
Improved: Lists now show a loading placeholder while filtering/searching,
so the screen never looks stuck.
Fixed: Removed unnecessary broad photo/video permissions — photo selection
now goes through the Android system picker only.
Fixed: A crash opening contributions on events with no round set up yet.

## App Store — "What's New in This Version"

What's New:
• Contribution rounds (mchango) are now on mobile — view the list and
  totals, filter and multi-select, open a contributor's payment ledger,
  record a payment, add contributors in bulk, and set up a round (target,
  deadline, payment numbers, kamati contacts, message copy).
• Share contributor cards and reminders directly to WhatsApp and other
  apps from the share sheet.
• Filtering and searching now shows a loading placeholder instead of a
  blank pause, so it's clear the list is refreshing.

Fixes:
• Reduced the photo/video permissions the app asks for — picking a photo
  now relies solely on the system picker.
• Fixed a crash opening the contributions screen on events that don't
  have a contribution round set up yet.
